% ---- F1: replaces the last two sentences of the "Trajectory error and contact" paragraph ("We did not measure ... raw odometry.")
We also computed the trajectory error of the wheel odometry alone. The odometry contains the injected noise, and over the same 7 episodes with a defined error it averaged 2.54~m, compared with 0.57~m for the SLAM pose. The per-episode reduction averaged 72\% (95\% world-cluster bootstrap interval 14 to 86\%; per-episode values from 14\% to 94\%). In 4 of the 7 episodes the odometry was also corrupted by wheel slip during contact, so the comparison includes the correction of those errors. Noise was injected only in this campaign, so the comparison is specific to the simulated noise model and is not a general comparison of SLAM with wheel odometry.

% ---- F2: replaces "The cause of this behaviour has not yet been identified."
The cause was traced to the explorer. The start-up rotation ends as soon as the first map arrives, which leaves the robot facing a wall 0.5 to 0.75~m away and gives a first map of only about 0.5 to 0.7~m$^2$. The goal-snapping step counts unknown cells as blocked, so no cell reaches the 0.30~m clearance, the only frontier is blacklisted, and the explorer has no fallback, so the robot waits until the stuck rule ends the episode. This happened in seeds 101 and 103. The behaviour depends on the starting pose and is not caused by narrow corridors, which are 1.0 to 1.1~m wide.

% ---- F3: replaces "The dominant planner failure ... true pose was in free space."
The dominant planner failure in the logs was a refusal to plan because the robot's estimated pose, which is always the planner's start, placed its footprint within the inscribed zone of a wall (Nav2 error 205). In the two office episodes analysed, the estimated pose collided in almost every such event while the true pose almost never did. Over all 12 navigation episodes, about one third of these events were attributable to localisation error and about 60\% to the robot genuinely having ended up within footprint range of a wall, where the navigation stack has no recovery that moves it away; the rest were not explained. The events are planner log lines that include repeated retries from a few stuck poses, so they are not independent.

% ---- F4: replaces "The same height range is used by the Nav2 obstacle layers and the ground-truth rasteriser for evaluation, ensuring consistency between the generated and reference maps."
The Nav2 obstacle layers are configured with the same band, but their only input is a scan taken from five rows of the depth image at the camera height. The ground-truth rasteriser counts objects between 0.03 and 0.25~m, and the ground-truth grids of all six test worlds are identical for both upper limits.

% ---- F5: disclosure sentences for the navigation and exploration paragraphs
The navigation seeds 103 and 104 were added at the authors' request after the evaluation settings were frozen, once the office results of seeds 101 and 102 had been analysed, to restore seeds that had been cut from the original design to save time; all episodes are reported, so each world has four navigation seeds but three exploration seeds. 6 further goals were still unfinished when their episode ended; they are not part of the 178-goal denominator. Two measurement fixes were made before the first test episode: the recorder was changed because it stalled its subscriptions and under-counted camera frames, and a one-second tolerance now lets a goal sent just before the first motion command count.

% ---- F6: interval method sentence (add under both result tables)
Intervals for single worlds are 95\% bootstrap intervals over three or four episodes and are therefore very wide. Pooled intervals for coverage, completeness, trajectory error and the per-episode navigation success come from a two-stage bootstrap that resamples worlds and then seeds within a world; with only three worlds they are coarse and their coverage is not guaranteed. The pooled success rate over goals (29.2\%) uses a bootstrap over episodes.

% ---- F7: replaces the sentence at the start of the exploration-termination paragraph ("If no map is available within 3~s ... build an initial map.")
If no map is available within 3~s of start-up, the robot rotates at 0.4~rad/s for up to 8~s, and it stops rotating as soon as the first map with free cells arrives.
